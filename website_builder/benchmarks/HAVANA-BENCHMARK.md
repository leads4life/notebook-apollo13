# R3 ORIGINAL BENCHMARK 001 — CAFÉ BRISA VIEJA

Business type: Cuban coffee shop
Location: Havana, Cuba
Build mode: ORIGINAL
Visual direction: old Havana, old-world café character, weathered architecture, classic cars, Cuban coffee ritual
Image source direction: Pexels photography, localized for production
Page family used in the benchmark: Home, Menu, Story, Gallery, Visit

Why retained:
- proves R3 can create a customer-facing website without borrowing the Atlantic Meridian composition
- establishes that ORIGINAL mode can choose its own typography, page rhythm, imagery, and information architecture
- keeps the retrofit engine available for a separate class of job instead of forcing one method onto every business
