# Category Retrofit Landing Engine R2

Purpose: mass-produce premium category-specific SEO/PPC landing pages for the website-design business.

## Workflow

1. Supply a business type.
2. Run the category strategist prompt to create a `CATEGORY-SPEC.json`.
3. Supply/generate the image slots and one complete target-industry showcase screenshot.
4. Run `runtime/build_from_spec.py`.
5. Review desktop/mobile visually.
6. Repair until the page still feels like the Atlantic Meridian quality bar while belonging completely to the new category.

The renderer deliberately preserves the baseline composition grammar. The strategist is responsible for category-specific thinking.

See `examples/law-firm/` for the first R2 correction benchmark.
