# CATEGORY RETROFIT LANDING ENGINE R2

## Mission
Produce high-quality, bottom-funnel website-design landing pages for a supplied business category.

This fork is independent from the full website-design engine. It borrows composition, image, SEO and QA technology only.

## Gold baseline
The default structural baseline is:

`reference/ATLANTIC-MERIDIAN-BASELINE.html`

The engine starts from this baseline rather than a blank generic agency template.

## Baseline grammar — mandatory by default
1. Category-native full-bleed first screen.
2. Exact commercial-intent H1.
3. Proposal + proof/showcase CTA in the first view.
4. Category-understanding editorial split.
5. Six-subcategory photographic band.
6. “What should the website do before the prospect calls?” decision section.
7. A believable target-industry website shown as the proof.
8. Category-specific SEO / paid-search architecture.
9. Three high-intent category opportunity blocks.
10. Redesign / migration argument.
11. Buyer FAQ.
12. Hard proposal CTA.
13. Project-fit form.
14. Phone/call path when a phone is configured.

## Showcase-first proof rule
The page must not merely say that we understand the industry. It must SHOW a believable website for that industry.

The showcase site/image is the visual proof artifact, analogous to Atlantic Meridian inside the marine landing page.

A build fails if the showcase could be removed without materially weakening the sales argument.

## Reimagination rule
The structural grammar may remain recognizable across categories, but these MUST change:
- business-world imagery
- subcategories
- decision questions
- website jobs/features
- proof/showcase site
- SEO architecture
- vocabulary
- form choices
- FAQ
- conversion emphasis

If replacing one noun makes the page work for another category, the build fails.

## Image rule
Default image slots:
- IMG-001 hero
- IMG-002 through IMG-007 six subcategory images
- IMG-008 decision/proof photo
- IMG-009 target-industry showcase screenshot
- IMG-010 optional project-desk/avatar art

Final production output uses local assets. No remote-image dependency.

## SEO / PPC rule
The primary owner is normally a decision-stage query such as:
- `[business type] website design company`
- `[business type] website design`
- `website design for [business type plural]`

Do not manufacture unsupported search-volume claims. Search-volume validation lives upstream from this production engine.

## Truth rule
Never invent real reviews, case results, awards, licenses, certifications, rankings, office addresses or customer proof. Demo concept sites must be clearly treated as concept/showcase work.
